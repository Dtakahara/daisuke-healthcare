# トレログ

大介さんがジムに行く前に「今日のトレログ」と打つ。
**ゴールはスマホのメモにそのまま貼れるコードブロック1つ。**前置きも解説も足さない。
帰ってきたら実績を貼るので、そこで集計して蓄積する。この2つが1セット。

---

## A. テンプレートを出す（「今日のトレログ」と言われたとき）

### 手順

1. **正本とトレログを復号する。**`src/` が無ければ大介さんにパスフレーズを聞く。
   ```bash
   SITE_PW='<パスフレーズ>' python3 crypt.py extract
   ```
2. `src/トレログ.md` の**一番上のセッション**（＝前回）と、
   `src/健康管理プロファイル.md` §3 のメニュー表・レップレンジ・増量条件を読む。
3. 種目ごとに今日の重量を決める（判定ルールは §C）。
4. **コードブロックを1つだけ出す。**日付は今日。重量は入れる。**回数は空欄のまま。**
5. コードブロックの下に、**前回から変えた種目だけ**を1行ずつ。変えていない種目は書かない。
6. 増量が3種目を超えたら**優先順位を付ける**。
   ただし「決め打ちが解消して一斉に軽さが露出した」ような回は、
   全部上げてよい。切り分けが要るのは**伸びないとき**であって、**明らかに軽すぎるとき**ではない。

### 出力の書式

- 並び順は**ルーチンの実施順**（正本§3のメニュー表の順）。
- 「重量x」まで書いて回数は空ける。左右をやる種目にだけ `※左右2セットずつ` を付ける。
- **3回連続で未実施の種目はテンプレートから外す。**やった日に手で足せばいい。
- **コードブロックの外に余計な行を入れない。**貼って使えることが唯一の成否条件。

---

## B. 実績が貼られたとき

その場で返すのは3つだけ。①**総挙上量の推移** ②**停滞種目** ③**次回重量**。

- **総挙上量 = 重量 × 総回数。**`※左右2セットずつ` は記載セット数×2で数える。
- **メニューが違う回どうしを直接比較しない。**種目構成が変わった回、ゴル練の後の回は
  交絡として明記し、比較から外す。
- **停滞の定義: 同じ種目で3セッション連続、総挙上量が伸びていない状態。**
  そこだけ手を打ち、伸びている種目は触らない。
- **総挙上量が下がっていても、内訳が「決め打ち→限界」に変わっていれば後退ではない。**
  10,10,10 が 11,9,9 になるのは質の向上。数字だけ見て後退と判定しない。
- 返したら **`src/トレログ.md` に追記して build → push まで済ませる。**
  push していない記録は存在しないのと同じ。

## C. 判定ルール（正本§3が正・ここは実行用の要約）

| 前回の実績 | 今日 |
|---|---|
| 全セットで**上限回数に到達** | **+2.5〜5kg**（ケーブルはスタック1段） |
| **レンジ超過**（上限の1.3倍以上） | Epleyで逆算する。**1RM ≒ 重量 ×(1 + 最高回数/30)**、そこから `1RM ÷ (1 + 目標回数/30)` で今日の重量。**セット間で回数が落ちていない回は、いちばん多いセットを採用する**（前半で止めていた証拠なので） |
| どこかのセットが**下限割れ**（8〜12なら7回以下） | **据え置き。**全セット揃うまで動かさない |
| レンジ内で揃っている | 据え置き |

- **自重種目は回数で伸ばさない**（どれが自重かは正本§3のメニュー表）。
  レンジ超過なら**テンポ（静止秒数）か可動域**を上げ、**重量の位置にその変数を置く**
  （例 `<種目> 3秒x`）。回数を伸ばす方向は時間を食うだけで刺激が入らない。
- **漸進（重量増）の対象外と指定された種目**が正本§3にある。可動域が目的なので重量を追わない。
- **記録しない種目**も正本§3で指定されている。漸進の信号が乗らないものは書かせない。
- **重量の数え方に例外のある種目がある**（バーの重量を足す等）。正本§3の記録規約に従う。
- **セット数が設計より少ない種目は、重量より先にセット数を埋める。**
  重量を1gも増やさずに総挙上量を増やせる、いちばん安いレバー。

---

## D. 毎回見るチェック（黙って確認して、引っかかったときだけ言う）

- **レンジ超過が同時に3種目以上** → 重量ではなく**レンジ設定か記録運用**を疑う。
- **同じ数字が全セットで揃っている**（10,10,10 等） → 限界ではなく決め打ちの疑い。
- **3回連続で落ちている種目** → 「下から削る」が効いている証拠なので責めない。
  ただし**その種目が症状ケア枠だったら別**。症状が再燃していないか確認し、
  必要なら毎晩ルーチン側へ移す。落とすのではなく仕組みで解く。
- **開始・終了時刻とレストが未記録** → 2回続けて欠けたら、その2つだけを頼む。
